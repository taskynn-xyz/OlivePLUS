OlivePLUS 1.0.1

Changes compared to vanilla Olive 0.1.2

OlivePLUS is a fork of Olive 0.1.2, the last release of the original Olive non-linear video editor. Everything listed below is new or changed in OlivePLUS 1.0.1; the upstream 0.1.2 feature set (timeline, project/media handling, transitions, the original effects, export to FFmpeg formats) is still there underneath.

New in 1.0.1

  • 3D nulls are a pivot: for a parented 3D layer, rotation and scale now turn around the centre of the null instead of the layer's own centre, so a group of children orbits and scales as one object from that central point.
  • Camera rigs: a camera layer can be parented to a 3D null - moving the null trucks the camera, rotating it orbits the camera around the null, and the camera keeps aiming at its transformed point of interest with no camera keyframes.
  • Glow methods, no more streaking: Deep Glow, Neon Glow, Inner Glow and Bloom each gained a Method picker with their own kernels, and all of them sample with a per-pixel jitter, so the glow is a smooth halo instead of the spoke-like streaks a fixed kernel leaves.
  • Colour swatches: a colour field in the effect controls now shows the colour it holds (contrasting border, accent border on hover, faded fill when disabled) instead of looking blank.
  • The text stylisers Gradient Sweep, Alpha Bevel and Inner Glow are filed under Stylize, with the rest of the look effects.

Playback and performance

  • Playback Quality (Playback > Playback Quality, and a button in both viewer toolbars): Full, 1/2, 1/4, 1/8 and 1/16 preview resolution, saved with the configuration. Exports always render at full resolution.
  • Changing the preview quality mid-session rebuilds every open clip's framebuffers, so the preview is never drawn into a stale buffer of the wrong size.
  • Effect shaders are told the resolution of the buffer they actually draw into, so shaders that work from gl_FragCoord / resolution stay exact at every quality setting.
  • No mipmap chain per blit: the render pipeline samples 1:1 with bilinear filtering, and the displayed frame still gets mipmaps once per paint. Removed a full-frame copy per clip per frame that nothing read.
  • GPU Acceleration level (Preferences > General): pick how hard Olive leans on the graphics card. Light turns multisampling off, keeps vsync on and never previews above half resolution, Balanced uses 4x multisampling at the Playback Quality you choose, and Aggressive raises that to 8x and switches vsync off so the viewer renders as fast as the GPU can. Preview resolution is the setting that actually moves GPU load, so Light is the one that makes a visible difference on a heavy timeline. The choice is applied when Olive starts, so it takes effect on the next launch.
  • Preview Threads (Preferences > General): how many CPU threads each decoder may use while preparing previews, or Automatic to let it use every core. Compositing the preview runs on a single GPU render thread, so this controls the decoding half of playback load only.
  • GPU selection (Preferences > General): on a machine with more than one graphics adapter, choose which one Olive renders on, or leave it on Automatic. Olive lists the adapters the system reports, marks the integrated ones, and asks Windows and the driver for the chosen adapter (the same per-application preference the Display settings write), with the NVIDIA Optimus and AMD PowerXpress request as a fallback for older drivers. Applied when Olive starts.

3D, motion graphics and parenting

  • 3D Transform effect: Position X/Y/Z, Rotation X/Y/Z, Scale, Perspective, Anchor Point, Opacity and the same motion blur rows as the Transform effect. The quad is projected per corner with a real perspective divide, so a keyframed Y rotation is a true card flip.
  • Null layers (draw nothing, carry a transform) and After Effects style parenting: parent from the clip's Parent submenu or the Clip Properties dialog. The parent's transform is applied on top of the child's own, chains are supported up to 32 links, loops are refused and every link is undoable. Parent choices are limited to the track directly above/below, and a clip shows its parent in a badge on the timeline.
  • 3D Null Layer: a null carrying only a 3D Transform. It drives clips that have a 3D Transform of their own, and a flat clip ignores it entirely.
  • Camera layer (Timeline > Add > Camera, also a "Camera" effect) with Position, Point of Interest and Zoom. Like After Effects, it only affects 3D layers - a clip without a 3D Transform is composited flat and never sees the camera.
  • A camera layer can be parented to a 3D null, which acts as a camera rig: moving the null trucks the camera, rotating it orbits the camera around the null, and the camera keeps aiming at its (transformed) point of interest, with no camera keyframes needed.
  • Real spatial parenting: a clip with a 3D Transform composes its parent chain in scene space and projects it, so a child of a rotated 3D null is foreshortened in depth instead of being sheared by a flat matrix.
  • A parented 3D layer's own rotation and scale pivot on the centre of the 3D null, not on its own centre, so a group of children orbits and scales as one object from that central point. Unparented 3D layers, and camera projection, still work around the layer itself.
  • Motion blur on Transform, Shake and 3D Transform (Shutter Angle, Shutter Phase, Blur Samples); the pass only runs on frames where the pose actually changes.

Layers and timeline

  • Adjustment layers: no media of their own; their effect chain runs on the frame already rendered below them, so transparent effects behave as masked adjustments.
  • Shape generator (Add > Shape, also the Shape effect): rectangle, ellipse, polygon, star and line with size, position, rotation, corner radius, fill, gradient, stroke, animated trim and feather.
  • Blending modes: the full standard set (Darken, Multiply, Screen, Overlay, Soft/Hard Light, Difference, Hue, Saturation, Color, Luminosity and the rest) instead of only Normal.
  • Rename layers in place: right-click > Rename Layer or F2, commit with Enter, cancel with Escape; undoable.
  • Effects render on top of the transform: plain image effects (blur, colour, glow, ...) are applied after the clip has been placed in sequence space, so they wrap the transformed image instead of being baked inside the clip's source rectangle.

Text and titles

  • The text renderer was rewritten around glyph outlines, so a title can have a real gradient fill across the whole text, a true stroke outline, and a blurred silhouette drop shadow.
  • New Title Text generator with Font, Size, Bold, Italic and Color as effect fields, so the panel's font is authoritative. Add > Title now creates a Text clip.
  • Rich Text effect gains Gradient Fill / Colour A / Colour B / Gradient Angle, Outline, Outline Colour and Outline Width, appended after the shadow rows so old projects still load.
  • The Edit Text dialog's font and formatting toolbar now applies to the selection, or to the whole document when nothing is selected, and no longer loses the font you picked.

Effects

Dozens of new effects, all keyframable and all preserving the clip's alpha. They live in effects/community (shader effects) plus the new internal Transform/3D Transform.

  • Motion graphics: Linear Wipe, Iris Wipe, Shape Matte, Duotone, Long Shadow, Repeater Grid, Light Leak, Zoom Blur, Chromatic Aberration, Glitch Blocks, Grid Collage, Spotlight, Halftone.
  • Text stylisers (Stylize, stay inside the layer's alpha): Gradient Sweep, Alpha Bevel, Inner Glow.
  • Lighting: God Rays, Deep Glow, Anamorphic Streak, Volumetric Fog, Light Sweep.
  • Glow methods: Deep Glow, Neon Glow, Inner Glow and Bloom each have a Method picker (Gaussian / Bokeh / Anamorphic, Soft Halo / Crisp Lines / Wide Bloom, Soft / Crisp / Directional, Gaussian / Box / Bokeh). Their sampling is jittered per pixel, so the glows are smooth halos instead of the spoke-like streaking a fixed kernel leaves.
  • Stylize: Pencil Sketch, Comic Ink, Bleach Bypass, Cross Process, Threshold, Stained Glass, Hex Mosaic.
  • Distort: Barrel Distortion, Liquid Melt, Mirror World, Shockwave, Pixel Stretch, Voronoi Shatter, Kaleidoscope, Displacement Map, Turbulent Warp.
  • Retro and stylised looks: CRT, Old Film, Hologram, Heat Vision, Neon Glow, Dither Crush, Oil Paint, Anaglyph 3D, Lens Flare, Bloom, Bokeh Blur, Denoise, Sharpen, Find Edge, Glitch, Gradient, Radial Wipe.
  • Wacky: Infinite Tunnel, Lava Lamp, ASCII Mosaic, Bubble Wrap, Psychedelic Haze.

Interface

  • Fluent-style stylesheet: flat rounded controls, the Microsoft accent colour, underlined panel tabs, rounded menus, slim scrollbars, rounded progress bars, sliders and checkboxes - for both the dark and light themes. A custom CSS file still overrides it.
  • The application is rebranded as OlivePLUS (window title, About box, welcome dialog, status bar, icon, installer) with a motion-graphics splash notice, while the settings/cache folder is deliberately still called "Olive" so existing settings and recent projects keep working.
  • Help > Changelog: opens this document.

Export

  • An Encoder row in the Export dialog: Software (CPU) or NVIDIA NVENC for H.264/H.265. NVENC is probed with a throwaway encoder before use and silently falls back to the software encoder when no NVIDIA GPU/driver is available, so it can never break an export.

Fixes and compatibility

  • 2D clips and titles no longer pick up a garbage perspective weight in one corner, which used to shear them as if they stood in 3D space.
  • Null layers no longer composite anything: previously a null could black out or white out everything below it, because its motion blur pass sampled an unbound texture.
  • Null and Shape objects can be placed on video tracks again; they were previously only accepted on audio tracks.
  • Qt 5.15 build fixes (missing transitive includes) and a Radial Wipe shader that used the GLSL 1.30 texture() call now compiles as GLSL 1.10.
  • The build still requires FFmpeg 4.x: vanilla Olive 0.1.2 uses APIs that FFmpeg 5.0 removed.
